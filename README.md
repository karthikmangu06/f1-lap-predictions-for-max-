This is a repo consists of my weekend project which predicts the lap time of my favourite f1 driver MAX VERSTAPPEN.
I have built this project to understand whether machine learning models can predict the lap times of a driver.
if yes, what will be the accuracy, errors, simply to say within what margin my model can predict accurate laptimes.
the uncontrollable variables like weather, red flags, crashes, yellow flags and etc. how do they effect my model.
on some tracks it's performing better like miami grand prix. the reason behind it is-very less physcial alterartions on the track and almost consistent and predictable weather conditions.
on some tracks it's not performing like the tracks which appear in the f1 calendar alternatively or on contract basis like - japan since they have less data to be trained on
also the predictions are off by some considerable marigin for the tracks which are physically altered - abu dhabi (yas marina circuit).
on some tracks it's performing by considerable margins like Las Vegas which have more historical data to be trained on.
